# Version

Current version: **v0.1.0**

## Scope

This is the first public-ready version of `stat-toolkits-builder`.

It includes:

- factory instructions for creating `stat-toolkits-*` repositories;
- self-contained reference specs for minimax-rate and EIF-style toolkits;
- generic v0.1 templates;
- a lightweight scaffold script;
- basic template and registry validation.

It does not include full vendored copies of the reference toolkits. Those
repositories remain external.
