# {{TOPIC}} research-problem protocol

Use research mode when no exact theorem, formula, or registry entry matches.

The goal is a useful derivation record, not an overconfident final answer.

## Steps

1. Normalize the problem.
2. State the closest known problem classes.
3. Propose candidate routes.
4. Work from first principles as far as possible.
5. Try validation checks and special cases.
6. Record failed attempts that reveal real obstructions.
7. Label the final status honestly.

## Obstruction ledger

If unresolved, include:

```text
Attempted step:
Why it was needed:
What was tried:
Where it failed:
What assumption or lemma would resolve it:
```

## Status labels

Use one of:

```text
derived and verified under stated assumptions
candidate result with unresolved verification
partial result only
closest known result only
identified but validation incomplete
unidentified or not applicable
nonregular or ill-posed as stated
```
