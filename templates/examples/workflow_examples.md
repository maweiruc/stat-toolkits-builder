# {{TOPIC}} workflow examples

Copy and adapt these prompts.

## Inbox prompt

```text
Please read problems/latex_inbox/problem_001/problem.tex and use the
{{TOPIC}} toolkit. If notes.md is missing, create it first. Write the detailed
answer to solution.md.
```

## Chat prompt

```text
Please use the {{TOPIC}} toolkit in this folder.

Problem:
...

Please normalize the problem, choose the mode, derive or check the answer,
validate it, and state caveats.
```

## Research prompt

```text
This may not match a standard result. Use research mode.
Build a first-principles derivation or proof record.
If unresolved, explain exactly where the derivation fails and what would be
needed to finish it.
```
