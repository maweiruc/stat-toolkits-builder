# Generated toolkits

Generated toolkits should be created here:

```text
tools/stat-toolkits-<topic>/
```

The builder itself is self-contained and does not vendor full reference
toolkits. Use the included reference specs instead:

- `examples/minimax_toolkit_spec.md`
- `examples/eif_toolkit_spec.md`

Full reference repositories, when needed:

- https://github.com/maweiruc/stat-toolkits-minimax
- https://github.com/maweiruc/stat-toolkits-eif
